## Log de sesión real (obligatorio, distinto a las capturas)

No es una captura — es un archivo de texto/JSON con una sesión real, no
de prueba. La forma más rápida: en la app, **Perfil → Copia de
seguridad → Exportar mis datos (.json)**, con los productos reales que
ya cargaste estos días (arroz, carne, lentejas, leche…). Guardá ese
archivo acá como `log-sesion-real.json`.
